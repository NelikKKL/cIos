# nano-clone для cIos

Команда `nano` / `nano <файл>` в шелле. Реализовано в `kernel/src/nano.rs`
(логика/состояние) + `kernel/src/terminal.rs::draw_nano*` (рендер).

Есть и вторая, независимая реализация того же самого на C — команда
`nanoc [файл]`, оба варианта доступны параллельно. Подробности,
отличия и (важно) правила работы с памятью — в NANO_C.md.

## Почему это не "исходники nano, только скомпилированные"

Оригинальный nano.c требует то, чего в freestanding no_std ядре cIos
нет и в обозримом виде не будет:

- **ncurses/termios** — cIos рисует текст сам, напрямую в framebuffer
  (`text::draw_text`), а не через терминальный эмулятор с ANSI-кодами.
- **POSIX-файлы** — у cIos своя RAM-FS (`fs.rs`) с другим API.
- **fork/exec** — нужен для ^T (spellcheck через aspell) и линтера;
  в cIos вообще нет процессов.
- **regex.h, locale/gettext** — нет ни regex-движка, ни локализации.
- **libc/glibc** — cIos использует `core`+`alloc`, не glibc.

Поэтому это заново написанный на Rust клон поведения и внешнего вида
nano, а не порт его C-кода. Экранная раскладка (title bar / тело /
статус-строка / панель горячих клавиш) сделана по образцу
`winio.c::titlebar()/bottombars()` из оригинала — см. цитаты путей и
логики в комментариях `nano.rs`.

## Что реализовано

Движение: стрелки, ^B/^F/^P/^N, ^A/Home, ^E/End, PgUp/PgDn (^Y/^V),
^Left/^Right (прыжок по словам), Del/^D, Backspace/^H.

Редактирование: вставка символов, Enter, Tab, indent/unindent
(M-}/M-{).

Пометка и вырезание: ^^ / M-A (Mark), ^K (вырезать строку целиком —
или помеченный регион, если Mark активен; несколько ^K подряд
накапливаются в один буфер вставки, как в оригинале), ^U (вставить).

Поиск/замена: ^W (Search, без учёта регистра, с переносом в начало
буфера), M-W (повторить поиск), ^\\ (Replace — **упрощено**: заменяет
ВСЕ вхождения сразу, без пошагового подтверждения Yes/No/All/Cancel,
как в оригинале).

Прочее: ^_ (Go To Line[,Column]), ^R (Read File — вставляет файл в
позицию курсора), ^J (Justify — переносит абзац; **упрощено**: фиксированная
ширина в 72 символа вместо реальной ширины окна), ^C (позиция курсора),
^O (сохранить, с запросом имени для нового файла), ^X (выход, с
диалогом Save modified buffer? Y/N/^C), ^G (экран справки), ^L
(no-op "Refreshed" — полный кадр и так перерисовывается по мере
надобности).

## Осознанно не реализовано

- **^T spellcheck/linter** — нужен внешний процесс, в cIos их нет.
- **Переключение в regex-поиск (M-R)** — нет regex-движка. Обычный
  (не-regex) поиск в самом nano и без этого не требует regex — это
  подтверждено в `search.c` оригинала (`ISSET(USE_REGEXP)`), так что
  сам факт поиска здесь есть, просто без regex-режима.
- **Undo/redo (M-U/M-E)** и **мультибуферы (M-F, M-</M->)**.
- Более редкие переключатели: мышь, suspend, softwrap, DOS/Mac
  переводы строк, backup-файлы, execute-command, word count (M-D),
  автодополнение (^]), парная скобка (M-]), комментирование (M-3).
  Можно добавить по мере надобности — архитектурно ничего не мешает.

## Известные упрощения рендера

- Заголовок центрируется проще, чем в оригинале (без многоточия при
  обрезании длинных путей).
- Горизонтальная прокрутка длинных строк есть (с `$` по краям, как в
  оригинале), но управляется общим смещением курсора, а не отдельно на
  строку.
- Шрифт cIos сейчас запекает только ASCII 0x20..=0x7E (см.
  `font.rs`) — кириллица и вообще всё не-ASCII в тексте не отрисуется
  (будет "дыркой"), это ограничение всей ОС, а не отдельно nano-режима.

## Не проверено сборкой

В песочнице, где это писалось, нет ни сети, ни установленного Rust
toolchain — собрать и прогнать `make kernel` не удалось. Код
вычитан вручную (типы, заимствования, сигнатуры), но настоящую сборку
стоит сделать первым делом. Отдельно стоит риск: `pc_keyboard`
`KeyCode::Home/End/PageUp/PageDown/Delete` — эти варианты не
использовались нигде в исходном коде cIos, и без доступа к
документации версии `pc-keyboard = "0.9"` их точные имена не
перепроверить. Если сборка ругнётся на них — посмотри
`cargo doc -p pc-keyboard --open` или исходники крейта и поправь
имена вариантов в `nano.rs` (`handle_normal_key`).

## Новые/изменённые файлы

- `kernel/src/nano.rs` — новый, вся логика редактора.
- `kernel/src/terminal.rs` — добавлены `draw_nano`/`draw_nano_panel`.
- `kernel/src/main.rs` — новый `Mode::Nano`, вход по команде `nano
  [файл]`, рендер-хуки.
- `kernel/src/shell.rs` — `nano` добавлен в список команд.
- `kernel/src/fs.rs` — добавлена `fs::write()` (создать-или-перезаписать
  файл), нужна для ^O.
- `kernel/src/keyboard_queue.rs` — теперь хранит не просто `DecodedKey`,
  а `KeyEvent{ key, ctrl, alt }`.
- `kernel/src/interrupts.rs` — трекает состояние Ctrl/Alt напрямую по
  сырым PS/2 скан-кодам (Set 1), независимо от `pc_keyboard`, потому
  что тот с `HandleControl::Ignore` не превращает Ctrl+буква в
  управляющий байт — а почти все хоткеи nano это Ctrl+буква.
